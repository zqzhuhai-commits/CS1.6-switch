# 欢乐谷地图纹理兼容性测试 03

适用于用户提供的可运行 FWGS 0.20 Switch 包，以及出现问题的 happyvalley_lt.bsp、happyvalley_lt_fix.bsp。尚未真机验证，不能保证解决花屏。

完全退出游戏，先备份 SD 卡上的 /switch/CS16/cstrike/opengl.cfg。把本包 03-pot-textures 目录内的 switch 文件夹复制到 SD 卡根目录，覆盖配置后重新启动。在原来出错的同一位置转动视角测试，再对比 de_dust2。

本方案从参考包原配置生成，只将 gl_texture_npot 从 1 改为 0；没有累加无效的补丁 1、2。引擎将使用非 NPOT 的尺寸兼容路径，可能改变清晰度或性能。无需重新安装 NSP。

两张地图的几何与贴图数据一致，贴图全部内嵌。它们含有 256×192 等非 2 的整数次幂尺寸贴图，这只是选择此项测试的依据，尚不能证明这些贴图导致花屏。_fix 文件名不代表修复了该渲染问题。

回退时恢复自己的配置备份；也可以把 rollback 内的 switch 文件夹复制到 SD 卡根目录，恢复用户参考 ZIP 的原配置。完全退出并重新启动后生效。

请反馈：两张欢乐谷地图是否仍花屏，以及 de_dust2 是否正常。如果仍无效，恢复原配置，继续调查引擎纹理与几何提交路径；本包不宣称修复了着色器。
